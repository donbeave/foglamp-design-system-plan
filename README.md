## Cost-Optimized Model & Effort Pyramid Summary (`Luna` < `Terra` < `Sol`)

Backed by OpenAI's official specifications ([GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra), [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Model Selection Guide](https://developers.openai.com/api/docs/guides/model-selection), and [Responses Multi-Agent Guide](https://developers.openai.com/api/docs/guides/responses-multi-agent)):

| Tier & Model Family | API Price (In / Cached / Out per 1M) | Effort Tiers Used | Share of Work | Official Strengths & Assigned Workload |
| :--- | :---: | :--- | :---: | :--- |
| **Tier 1: `GPT-6-Luna`**<br>*(Fastest & Cheapest Worker — `180M TPM`)* | **`$0.10 / $0.01 / $0.50`**<br>*(20× cheaper than Sol)* | `low`, `medium`, `high`, `max` | **~72%** | • **`low` (~26%)**: *"Fine-grained edits, well-scoped problem-solving, and simple data extraction"* — verbatim copies (48 decoupled Base UI primitives, 25 `BrandLogos`, `.woff2` fonts, `ai-workshop.webp`, 2,094-line `mock-data.ts`), barrel `index.ts` files, `meta.json` trees, CLI checks (`tsc`, `vitest`, `shadcn build`, `bun run build`).<br>• **`medium` (~20%)**: Pure TS utilities (`format.ts`, `range.ts`, `trace-timeline.ts`, `payload-messages.ts`, `hooks.ts`), simple leaf widgets (`ModelLogo`, `AgentIcon`, `ProjectIcon`, `CustomerAvatar`, `ToolIcon`, `SpanTypeChip`, `CopyIcon`, `CopyButton`, `Stat`, `RelativeTime`, `SunsetCard`, `NodeFlow`), all 56 UI primitive `.story.tsx` files, and `registry.json` generation.<br>• **`high` (~16%)**: Component reference `.mdx` pages (`primitives/*`, `widgets/*`, `charts/*`, `figures/*`, `blocks/*`), standard widget/figure `.story.tsx` files, and single-file moderate widget decoupling (`PageHeader`, `StatCard`, `RangePicker`, `CodeBlock`, `Markdown`, `AnimatedApiKey`, `ContextChip`, `QuotaCardView`, `ThemeSwitcher`, `UserMenuView`).<br>• **`max` (~10% — `66.6%` DeepSWE v1.1 at 1/10th Terra's price!)**: *"Solving problems with clear constraints"* — verifying the 8 custom-logic primitives (`Button`, `Badge`, `DRAWER_BUTTON_CLASS`, `Select` auto-label collector, `Sheet` floating variant, `Table` `ResizeObserver` + `interactive` row, `Tooltip`, `Sonner`), `<FoglampLinkProvider>`, `@foglamp/prompts` LCS diff/slot engine, all 11 `evilcharts/*` files + `CostBreakdownView` & `ToolBreakdownView`, all **22 Landing Figures**, `DriftingFogCtaBlock`, `CuttingMatFooterBlock`, `HudSimulatorBlock`, Auth/Onboarding blocks, and `OriginalAuthorsBlock`. |
| **Tier 2: `GPT-6.1-Terra`**<br>*(>3× Faster Visual, Writing & Computer-Use)* | **`$1.00 / $0.05 / $5.00`**<br>*(50% cheaper & >3× faster than Sol)* | `low`, `medium`, `high` | **~21%** | • **`low` (~5%)**: *"Clear, natural writing based on supplied material"* — authoring flagship narrative prose (`index.mdx`, `credits.mdx` tribute to **Gustavo Fior** `@gustavo-fior`, `foundations/*.mdx`) + fast inter-wave gatekeeper checks.<br>• **`medium` (~9%)**: **`MMMU-Pro` Visual Reasoning** — Wave 0 TanStack Start + `@fumadocs/base-ui` + `@fumadocs/story` + Tailwind v4 CSS token pipeline (18 `--custom-shadow*` tokens + `@toolwind/corner-shape` squircles), `scan/layout.ts` 2-pass `elkjs` orthogonal layout math, `FoglampStoryPanel`, `PayloadView` + `RunExchange` drawers, `PromptProseView` + `PromptVersionsView`, `EvalScores`, `AppShellBlock`, and 7 Dashboard Page Blocks.<br>• **`high` (~7%)**: **`Terminal-Bench 4.0` (`50.3%` layout-shift fixes) & `Agents' Last Exam` Computer-Use** — `DataTable` + `Toolbar` (`ResizeObserver` + `motion.div layoutId` header portal-lifting), `ObservabilityGuideBlock` sticky scrollytelling, `SetupBoardBlock` patch editor, and **Live Browser Computer-Use Visual QA** across Light & Dark modes. |
| **Tier 3: `GPT-6.1-Sol`**<br>*(Multi-Agent Root & Connected Visual Systems)* | **`$2.00 / $0.10 / $10.00`**<br>*(1/5th the price of Astra)* | `low`, `medium`, `high` | **~7%** | • **`low` (~2% — Lead Orchestrator / Root Coordinator `/root`)**: Official `multi_agent` root model (`2.1%` broken-tool error rate vs `28.7%` on `Luna`; `-32%` factual error reduction at `low` effort). Dispatches parallel subagents, tracks `TASKS.md`, enforces gates. **Never writes implementation code.**<br>• **`medium` (~3.5% — `75.2%` DeepSWE v1.1)**: *"Complex technical work and coordinated deliverables"* — `TraceTimeline` multi-phase waterfall, `FlowMapBlock` + `ScanBoardBlock` (`<BeamPulse>` WAAPI comets + crisp zoom), `FoggyLauncher` 6px SVG corner shelf + `FoggyWidgetView` rubber-band resize, and `FoglampHUD` Shadow DOM 240Hz spring.<br>• **`high` (~1.5% — ONLY 2 APEX TASKS)**: *"Polished deliverables, connected visual systems"* — (1) `Hero3DDemoBlock` 3-Beat `transform-3d` perspective assembly + Beat 0 dark-mode 8-bit sRGB anti-flicker tween + 7-tab/5-detail `DashboardDemo`; (2) Wave 5 Final Whole-Portal Connected Visual System & Attribution Sign-Off. |
