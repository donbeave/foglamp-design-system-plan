# Read-only provenance preflight

Run `python3 results/qa/w6-provenance-preflight/inventory.py` from the plan checkout to refresh `manifest.json`; run it with `--self-test` to exercise strict-comparison negative fixtures. The tool reads the current implementation working tree and the pinned upstream Git blobs, writes only this directory, records SHA-256 hashes of both bodies and full current files, and verifies upstream HEAD. Results are a snapshot and must be rerun after concurrent edits.

The snapshot has 266 files: 46 proposed copied-1-to-1, 200 proposed modified, and 20 proposed tailrocks-original. The earlier 29 unmapped files now have review decisions, and the 21 heuristic flags have manual primary-source dispositions. Two modified files carry reviewed multi-source flags. A classification is a preflight recommendation, not a final legal or provenance determination. Candidate paths are validated against the pinned Git tree and derived from the W5 harness map or filename plus line similarity; they require human review, especially weak, ambiguous, and possible multi-source cases. A match's existence and similarity do not prove derivation. Existing misleading headers are not authoritative. Determine primary paths and all significant inlined sources from source evidence before applying headers. This inventory does not complete W6-6C.

For copied status, the comparison is exact bytes after removal of an identifiable initial attribution block and optional leading use-client directive only. It performs no import, whitespace, AST, or type normalization. Similarity is solely a candidate-finding heuristic. W5 static reports used transpilation and therefore do not establish the stricter copied classification here; their residual dispositions remain useful review leads.

Seven currently redistributed assets were found in the design-system package and docs public directory; all seven have identical blobs at paths in the pinned upstream Git tree, recorded in the manifest. The local upstream root LICENSE and package NOTICE identify Apache-2.0 for project source, but no individual font or image license notices were located in the scanned project/upstream trees. In particular, the Inter font binary's independent license and third-party logo/image rights are not established by this scan: inspect authoritative accompanying notices before redistribution decisions. No binary is relicensed by this report. The scan excludes dependencies, generated outputs and other application directories; it is not an exhaustive dependency-license audit.

## Review decisions and secondary-source leads

`review.json` captures file-hash-bound decisions with primary and, when known, secondary paths. The seven dashboard mappings come from the W5 dashboard harness inventory; the eval placeholder maps to the pinned upstream `chip-placeholders.tsx`. The scan verification script is newly authored; its ten secondary paths are read as audit inputs, not claimed as copied script bodies. The other integration originals are barrels, adapters, a test, a declaration, and a composition. `lib/types.ts` is treated conservatively as modified from the trace timeline type and trace service shape.

`secondary-leads.py` searches pinned source blobs for long identical lines and writes `secondary-leads.json`. Some reviewed or dashboard files have possible secondary paths. Shared lines may be generic or duplicated upstream, so these are leads, not verified secondary attributions. These unconfirmed leads are nonclaims, not additional mapping blockers. The W5 source map and dashboard harness establish the principal candidate files; the curated review records host adapters and the confirmed inlined ScrollFade. The trace span shape also records its related service source.

Run `review.py` only when deliberately re-reviewing all curated decisions: it binds them to the then-current file hashes. Ordinary inventory refreshes detect later changes and flag a stale decision. `inventory.py` strips an identifiable attribution and client directive in either order, without normalizing the remaining bytes.

The 21 original heuristic flags were manually reviewed using source symbol and component correspondence and W5 evidence: 20 are host adapters or rewritten components with a known primary, and the utility is an exact generic re-export. No primary counterpart is currently unknown. Source maps are a review aid rather than automatic legal conclusions; re-run after changes. The self-test checks both header/directive orders, a one-byte import change, whitespace differences, and retention of non-attribution comments.
